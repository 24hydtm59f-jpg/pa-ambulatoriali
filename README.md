# Prestazioni aggiuntive ambulatoriali – Ortopedia Verduno

Pagina web per inserire gli ambulatori a gettone e generare la lettera mensile per la direzione.

- `index.html` – l'app (una sola pagina). In cima allo script ci sono indirizzo e chiave pubblica del progetto Supabase.
- `database/schema.sql` – tabelle e funzioni del database (Supabase > SQL Editor).
- `.github/workflows/sveglia.yml` – controllo giornaliero che evita la pausa del progetto Supabase gratuito.

I dati non stanno in questo repository: stanno nel database, accessibile solo con utente e password dell'app.
